# 15-Commit Development Guide

The Git history in this repository contains the following milestones in order:

1. Initialize Java console project structure
2. Add abstract User class
3. Implement Passenger and Admin classes
4. Add Train model and train records
5. Implement train search functionality
6. Add seat availability management
7. Implement Booking model and PNR generation
8. Add ticket booking functionality
9. Implement HashMap for booking records
10. Implement custom seat availability exception
11. Add custom train and booking exceptions
12. Implement custom FIFO waiting list queue
13. Add ticket cancellation and waiting list promotion
14. Implement PNR search and booking history
15. Complete console menu and test reservation workflows

To inspect the commits: `git log --oneline --reverse`.
